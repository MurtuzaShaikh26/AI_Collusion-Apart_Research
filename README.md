# Counterfactual replay as a plus factor

Sprint code for the Apart Research × Poseidon Research × AE Studio AI Collusion Research Sprint (23–25 Oct 2026). Track 2, question 2.3, with the say-versus-do element of question 2.2.

The question is what should count as convincing evidence of collusion between LLM agents. The method re-queries a logged agent with one part of its input changed (messages, partner prices, or the shared cost signal) and measures how much the price moves.

## What is pre-existing

`third_party/llm_cartel/environment/oligopoly.py` is copied verbatim from the Poseidon starter snapshot of [mattriemer/LLMCartel](https://github.com/mattriemer/LLMCartel). See `third_party/llm_cartel/ATTRIBUTION.md`. Everything else in this repository was written during the sprint.

## Setup


Copy `.env.example` to `.env` and fill in keys locally. Do not commit `.env`.
